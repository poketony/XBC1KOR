# Xenoblade New 3DS 한글화 에디터

2026-09-23 개발판. Wii 에디터와 같은 작업 흐름을 제공하는 별도 프로그램이다. 원본 RomFS는 읽기 전용으로 취급하며 실기·에뮬레이터 실행 검증은 하지 않았다.

## 실행

`3DS 에디터 실행.cmd`를 실행한다. 앞으로 실행 링크도 이 CMD 런처를 사용한다. Python, Tkinter, Pillow가 필요하며 현재 작업 PC에 설치되어 있다.

**게임 루트 열기**에서 `E:/Xenoblade/Xenoblade 3DS/ExtractedRomFS` 또는 그 상위 `Xenoblade 3DS` 폴더를 선택한다. `fsize.dat`와 `script` 폴더로 루트를 확인한다. 성공적으로 선택한 경로는 `n3ds_editor_settings.json`에 기억한다. 디스크가 빠져 있어도 기억한 경로는 유지한다. Wii 설정과 별개이며 미저장 편집 내용까지 복구하지는 않는다.

## 사용 흐름

1. `common`, `mapbdat`, `script`, `menu`, `font`, `ev` 등의 영역을 펼친다.
2. 이름이 표시된 파일을 펼쳐 내부 BDAT·BRLYT·TPL 등 문서를 선택한다. 선택 파일만 읽으며 전체 게임을 메모리에 올리지 않는다.
3. **문자열 / 자막**에서 행을 선택하고 수정한 뒤 **문장 반영**을 누른다. 다른 행·문서로 이동하거나 저장할 때도 입력 중인 문장을 반영한다.
4. BRLYT는 **텍스트 상자 속성**으로 상자 크기·글자 크기·간격·버퍼 용량을 수정한다. 일반 문장 편집은 지정한 런타임 버퍼를 줄이지 않는다. 명시적 축소는 속성 창에서 한다.
5. **이미지**에서 PNG 미리보기·추출·교체를 수행한다. TPL은 크기가 다른 PNG도 재포장한다(가로·세로 8의 배수, 각 4096 이하, 단일 밉). REV 내부 TPL도 후속 자원의 주소를 옮긴다. 바깥 TPL의 논리 크기는 유지하고 실제 텍스처 해상도만 바꾸며, 화면상의 레이아웃 크기를 바꾸는 기능은 아니다. MGBR/REM은 선택한 밉의 동일 크기 교체를 지원한다. ETC1 및 ETC1A4 색상 변경은 손실 변환 허용이 필요하다. ETC1A4 알파만 17단계 간격으로 바꾸면 RGB 압축 블록을 보존한다. 이미지 변환은 작업 스레드에서 처리한다.
6. BRFNA 폰트는 PNG 시트를 교체하거나 **폰트 문자표 / 폭**에서 기존 문자 코드·글리프 폭을 편집한다. 폰트 PNG는 내보낸 L/RGBA 모드를 유지하고 LA4의 16단계 값을 사용한다. 문자 코드 변경은 기존 sparse CMAP 범위 안에서 지원하며 충돌을 거부한다.
7. **수정본 저장**에서 원본 밖의 새 폴더를 지정한다. 수정 파일을 RomFS 상대 경로 그대로 출력하고 **갱신된 `fsize.dat`를 함께 출력**한다.

출력은 게임 전체가 아니라 변경분이다. 작업용 RomFS 복사본에 변경 파일과 `fsize.dat`를 함께 반영한다. 이 에디터는 ROM/CIA를 빌드하거나 설치하지 않는다. 저장은 임시 `.incomplete-…` 폴더에서 검증 후 최종 이름으로 바꾼다. 실패한 임시 출력은 사용하지 않는다. 원본 변경이 감지되면 저장을 거부한다.

## Wii와의 차이

| 항목 | Wii | New 3DS |
|---|---|---|
| 최상위 자원 | PKB/PKH | RomFS 폴더·파일 |
| 저장 인덱스 | PKH | fsize.dat |
| SB·BDAT·REV 텍스트 | CP932 | UTF-8 |
| BRLYT 텍스트 | UTF-16 BE | UTF-16 LE |
| 폰트 시트 압축 | Huffman8 / GX I4 | QuickLZ3 / LA4 |
| 일반 구조 정수 | 주로 BE | 주로 LE |

UTF-8로 한글을 저장할 수 있다는 사실과 게임 폰트가 한글 글리프를 가진다는 사실은 별개다. 원래 문자 슬롯에 한글 글리프를 넣는 방식이면 문자 매핑 JSON을 사용할 수 있고, 실제 Unicode 한글을 쓰려면 폰트 CMAP·글리프를 준비해야 한다. 자동으로 완성형 한글 폰트를 생성하지 않는다.

## 재포장 구현

- SB: 문자열 풀 전체 재구성, 공유 문자열의 서로 다른 수정 분리, 필요 시 16/32비트 포인터 선택, 후속 섹션 이동.
- BDAT: 문자열 풀 전체 재구성, 32비트 문자열 포인터·풀 길이 갱신. flag 3 암호화 테이블은 해제 후 재암호화한다. 끝의 정렬용 00/E3 패딩을 구분한다.
- BRLYT: txt1 문자열 버퍼·섹션 크기·파일 길이 갱신. 옛 문자열을 뒤에 누적하지 않는다.
- ARC·BDAT 묶음: 구성원을 다시 배치하고 주소·길이를 갱신한다.
- REV: 자막 슬롯을 재구성하고 자막 뒤 컷 데이터 시작 주소와 각 컷 참조를 이동한다. RED·컷 본문은 보존한다. 변환 전 값이 남은 다른 헤더 필드를 물리 파일 크기로 임의 치환하지 않는다. 이 경로의 실제 게임 로더 호환성은 실기에서 확인해야 한다.
- BRFNA: 기존 3DS 전용 QuickLZ writer로 수정 시트를 재압축하고 GLGR·TGLP 크기를 갱신한다. 변경하지 않은 시트·문자표는 보존한다.

파일당 읽기 64 MiB, 수정 캐시 128 MiB 제한은 메모리 보호용이다. 문자열 원래 길이 제한이 아니다. 실제 포맷 필드의 표현 범위를 넘는 값은 거부한다.

## CLI 텍스트 JSON 추출

```powershell
python codex-lab/n3ds_text_export.py "E:/Xenoblade/Xenoblade 3DS" "codex-lab/my-3ds-text"
```

선택 영역만 추출하려면 `--areas common mapbdat script menu ev`처럼 지정한다. 영역별 JSON에 파일 경로·중첩 경로·원본 해시·행/열 식별자·원문 바이트·제어문자와 `translation: null`을 보존한다. 동일 문자열을 합치지 않는다. `manifest.json`에서 오류와 미해석 데이터를 확인한다. 이 JSON을 자동 재삽입하거나 Switch 번역과 자동 매칭하는 기능은 포함하지 않는다.

실제 `common` 샘플 결과: `n3ds_editor_text_sample`, 138개 문서 / 41,489항목, 오류 0. 전체 영역 추출을 실행한 결과는 아니다.

## 검증과 현재 한계

`python -m unittest discover -s codex-lab -p 'test_n3ds*.py' -v`

10개 검사 통과: 기존 6개 통합 검사(GUI 탐색·문장 반영·루트 기억, 디스크 분리, 텍스트 증가·축소, 중첩 미수정 파일 보존, 실제 RomFS 변경 파일·fsize 저장, 실패 시 상태 유지, 암호화 BDAT, 레이아웃 속성, 폰트 PNG 및 문자표·폭)와 이미지 4개 검사. 추가 검사는 TPL 증가·축소, REV 다중 이미지 TPL 재배치와 자막·컷·다른 자원 보존, RGBA8 타일 순서와 ETC1A4 알파, 실제 REM 6개 형식의 교체 및 다른 밉·파일 바이트 보존을 다룬다.

`N3DS_EDITOR_CORPUS_RESULT.json`: BDAT 216개, SB 713개, BRLYT 77개, REV 140개에서 첫 문자열 증가·감소 및 다른 행 바이트 보존을 검사했다. 모든 문자열을 동시에 번역한 검사나 실기 검사가 아니다.

MGBR/REM은 RGBA8·RGBA4·RGB565·LA8·ETC1·ETC1A4의 동일 크기 교체를 실제 자료로 검사했다. MGBR/REM 해상도 변경과 밉 체인 재생성은 아직 지원하지 않는다. 지원하지 않는 이미지 변형은 경고로 표시하며 해당 문서의 텍스트 편집을 막지 않는다. 폰트의 새 시트·글리프 슬롯 확장, 범용 모델·애니메이션·음향 편집, ROM 빌드와 게임 적용 검증은 포함하지 않는다.

REV resident 읽기·자막·RED 순회와 TPL 크기의 소비 경로를 `code.bin`에서 대조했다. 그 주소 계산을 재포장 검증에 연결했고, 원본 REV 220개·별도 메뉴 TPL 114개가 통과했다. 물리 크기와 불일치하는 오래된 전체 길이 값은 보존한다. 실행 파일 근거와 정적 분석의 범위는 `N3DS_IMAGE_CODE_NOTES.md`, 원시 명령과 검사 결과는 `N3DS_IMAGE_LOADER_RESULT.json`을 참고한다. 이는 ARM 실행 에뮬레이션이나 게임 호환성 확정 검사가 아니다.
